壁纸设置

通过界面或配置文件管理你的 HTML 壁纸

来源

提示：部分网站设置了禁止嵌入（X-Frame-Options），将无法作为壁纸显示。

使用内置的极光动画背景。你也可以切换到「HTML 代码」自定义内容。

预设页面

勾上后壁纸窗口会被裁到只有面板这一块，面板之外就是你 Windows 原本的桌面壁纸 （不是"抠掉黑色"那种伪透明，是真的不画）。面板的位置 / 大小沿用下面的设置。

留空沿用默认毛玻璃面板；填 rgba(20,18,40,0.55) 直接指定颜色与透明度； 填 transparent 则面板完全透明、只剩文字浮在上面。 面板是整块窗口，半透明颜色是跟页面背景色混合（不是跟系统壁纸混合）， 想贴近系统壁纸观感就用不透明颜色。

桌面上的壁纸是不可点击的（桌面图标层挡在它上面，鼠标事件进不到页面）， 所以这里什么都能调：位置、大小、字号、速度、导入的文件，改完立刻出现在桌面上。

文件导入

如果当前壁纸 HTML 里有需要导入文件的部分（<input type="file"> 或 data-htmlbg-file 标记），会列在这里；给它绑定文件后，每次加载壁纸都会自动注入。
每个导入点都和「来源 → 本地文件」一样的操作：点「选择文件」挑文件，或直接在下面的路径框里填上相对 / 绝对路径再点「绑定文件」。
支持 Word（.docx）、PDF（.pdf）、PowerPoint（.pptx）、Excel（.xlsx/.csv/.tsv）、文本（.txt/.md）、图片、音视频。
